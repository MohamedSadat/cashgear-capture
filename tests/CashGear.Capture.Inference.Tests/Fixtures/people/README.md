# People for the segmentation test

Four official NASA portraits (works of the United States government: public domain), each cut to a webcam's 640 × 480 from the top of the portrait. Their sources are in `people.json`.

The outlines in `people.json` were traced by hand over a grid, looking at each picture, and checked by drawing them back over it. The test moves each person a little over five frames, 20 in all, with the outline moved the same way.

They are stand-ins for a webcam (formal portraits, a flag behind them). A real camera in a real room is a by-hand check (`docs/TESTING.md`, Phase 20).
