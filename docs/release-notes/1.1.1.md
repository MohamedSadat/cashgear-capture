# CashGear Capture 1.1.1

- With **Save to file** switched off, unsaved captures opened in the editor or copied to the clipboard no longer create image copies in Capture History.
- Dragging a rectangular region now captures as soon as the mouse button is released. Rounded regions still allow adjustments before confirmation.
