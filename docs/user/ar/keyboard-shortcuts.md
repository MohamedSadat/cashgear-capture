# اختصارات لوحة المفاتيح

يمكن تنفيذ كل شيء في CashGear Capture من لوحة المفاتيح. أسماء المفاتيح هي نفسها بالعربية لأنها تطابق المكتوب على المفاتيح.

## مفاتيح الاختصار (في أي مكان في Windows)

غيّرها من الإعدادات › مفاتيح الاختصار. ليس للعناصر المعلَّمة بـ«—» مفتاح حتى تعيّن واحدًا.

| الافتراضي | الإجراء |
|---|---|
| `PrintScreen` | التقاط منطقة |
| `Alt+PrintScreen` | التقاط النافذة النشطة |
| `Ctrl+PrintScreen` | التقاط الشاشة كاملة |
| `Ctrl+Shift+PrintScreen` | الالتقاط مع التمرير |
| `Ctrl+Alt+PrintScreen` | التقاط النص (التعرف الضوئي) |
| `Shift+PrintScreen` | بدء التسجيل أو إيقافه |
| `Ctrl+Alt+Shift+PrintScreen` | تكرار آخر التقاط |
| `Ctrl+Shift+D` | الرسم على الشاشة (أثناء التسجيل) |
| `Ctrl+Alt+Shift+T` | استخدام شريط أدوات الالتقاط أو التسجيل من لوحة المفاتيح (Tab وEnter، وEsc يعيد التركيز) |
| — | التقاط نافذة، ومنطقة بحجم ثابت أو حرة أو مضلعة أو بزوايا مستديرة، وعنصر، وقائمة مفتوحة |
| — | إظهار شريط أدوات الالتقاط أو إخفاؤه، والمكبّر، ومنتقي الألوان، والمسطرة، وخطّا التقاطع |
| — | الضغط للتحدث (مع الاستمرار) |

## قائمة منطقة الإعلامات

‏`Win+B` ينقلك إلى منطقة الإعلامات، ثم انتقل بالأسهم إلى أيقونة CashGear Capture (افتح **^** بـ Enter إن كانت مخفية)، ثم `Enter` أو `Space` أو `Shift+F10` لفتح القائمة. داخل القائمة: الأسهم، والحروف المسطَّرة (الحرف اللاتيني بين قوسين)، و`Enter`، و`Esc`.

## تحديد منطقة (للالتقاط أو التسجيل)

| المفاتيح | |
|---|---|
| `Enter` | التقاط المنطقة أو النافذة أو الشاشة المحددة |
| `Esc` | إلغاء |
| الأسهم (`Ctrl`: ‏10 بكسل) | تحريك المؤشر بكسلًا واحدًا |
| `Tab` | الحجم التالي (منطقة بحجم ثابت) |
| `Backspace` | التراجع عن آخر زاوية (مضلع) |

## العد التنازلي

‏`Esc` يلغي الالتقاط.

## محرر الصور

| المفاتيح | |
|---|---|
| `V` `A` `L` `R` `E` `D` `H` `T` `N` `B` `X` `C` `M` `O` `G` | التحديد، والسهم، والخط، والمستطيل، والشكل البيضاوي، والقلم، والتمييز، والنص، ورقم الخطوة، والتمويه، والتقطيع إلى بكسلات، والاقتصاص، والمنطقة، وبقعة الضوء، والتكبير |
| `Enter` (مع أداة) | إضافة عنصر بالحجم المعتاد في المنتصف (مع أداة التحديد: تحرير النص المحدد) |
| `Tab` / `Shift+Tab` | تحديد التعليق التوضيحي التالي / السابق (`Ctrl+Tab` يغادر الصورة) |
| الأسهم (`Shift`: ‏10 بكسل) | تحريك التعليق المحدد أو إطار الاقتصاص؛ وإن لم يُحدَّد شيء فتمرير العرض |
| `Ctrl+Shift`+الأسهم | تغيير حجم التعليق المحدد بكسلًا واحدًا |
| `Delete` | حذفه |
| `Enter` / `Esc` (أثناء الاقتصاص) | اقتصاص / إلغاء |
| `Ctrl+Z`، `Ctrl+Y` | تراجع، إعادة |
| `Ctrl+S`، `Ctrl+Shift+S` | حفظ، حفظ باسم |
| `Ctrl+C` | نسخ الصورة |
| `Ctrl+0`، `Ctrl+1`، `Ctrl++`، `Ctrl+-` | ملاءمة، ‏100%، تكبير، تصغير |
| `Space`+السحب | تحريك العرض |

الصورة نفسها تبقى من اليسار إلى اليمين كما هي على الشاشة، فالسهم `→` يحرّك إلى اليمين دائمًا.

## محرر الفيديو

| المفاتيح | |
|---|---|
| `Space` | تشغيل / إيقاف مؤقت |
| `←` / `→` | إطار للخلف / للأمام (المخطط الزمني يبقى من اليسار إلى اليمين) |
| `Home` / `End` | إلى البداية / النهاية |
| `S` | التقسيم عند رأس التشغيل |
| `I` / `O` | تحديد البداية / النهاية |
| `Delete` / `Shift+Delete` | حذف (النطاق أو المقطع) / حذف مع إغلاق الفراغ |
| `Esc` | إلغاء التحديد |
| `Tab` / `Shift+Tab` | تحديد المقطع التالي / السابق (`Ctrl+Tab` يغادر المخطط الزمني) |
| `↑` / `↓` | نقل المقطع المحدد إلى المسار الأعلى / الأدنى |
| `Alt+←` / `Alt+→` (`Shift`: ثانية) | تحريك المقطع المحدد إطارًا |
| `Ctrl+[` / `Ctrl+]` | قص بداية المقطع / نهايته إلى رأس التشغيل |
| الأسهم في المعاينة (`Shift`: ‏10 بكسل) | تحريك الصورة أو التعليق أو التكبير المحدد (عند رأس التشغيل) |
| `Ctrl+Z`، `Ctrl+Y` | تراجع، إعادة |
| `Ctrl+S`، `Ctrl+Shift+S` | حفظ المشروع، حفظ باسم |
| `Ctrl+E` | تصدير |
| `Ctrl++`، `Ctrl+-`، `Ctrl+0` | تكبير المخطط الزمني، تصغيره، ملاءمته |

## أدوات الشاشة

| الأداة | المفاتيح |
|---|---|
| المكبّر | ‏`+` و`-` للتكبير والتصغير، والأسهم تحرّك بكسلًا (`Ctrl`: ‏10)، و`Esc` للإغلاق |
| منتقي الألوان | الأسهم تحرّك بكسلًا، و`Enter` يلتقط اللون، و`Esc` للإلغاء |
| المسطرة | الأسهم تحرّكها (`Shift`: تغيير طولها)، و`Esc` للإغلاق |
| الرسم على الشاشة | ‏`1`–`4` القلم، والقلم المميّز، والسهم، والمستطيل؛ و`Ctrl+Z` تراجع؛ و`Delete` أو `Backspace` مسح؛ و`Esc` إيقاف |

## كل النوافذ

‏`Tab` و`Shift+Tab` للتنقل بين عناصر التحكم (وتأتي الأزرار السفلية في النهاية)، و`Alt` مع الحرف المسطَّر لفتح قائمة أو الانتقال إلى عنصر له حرف مسطَّر، و`Enter` للزر الافتراضي، و`Esc` لإغلاق مربع حوار أو الإلغاء. يقرأ «الراوي» وقارئات الشاشة الأخرى اسم كل عنصر تحكم، وتُتَّبع سمات التباين في Windows فور تشغيلها.
