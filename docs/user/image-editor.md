# The image editor

Every capture opens in its own editor window (unless Settings › Output says otherwise). Annotations stay editable until you save or copy.

## Tools

| Tool | Key | |
|---|---|---|
| Select | `V` | Click to select, drag to move, grips to resize (Shift keeps proportions); double-click text to edit it |
| Arrow, Line | `A`, `L` | Shift snaps to 45° |
| Rectangle, Ellipse | `R`, `E` | Outline, fill and line width; Shift for a square or circle |
| Pen | `D` | Freehand |
| Highlight | `H` | A highlighter: text under it stays readable |
| Text | `T` | Click and type (Arabic is joined and laid out right to left); Esc finishes |
| Step number | `N` | Each click places the next number |
| Blur, Pixelate | `B`, `X` | Hide part of the picture |
| Crop | `C` | Drag the part to keep, then Enter |
| Area | `M` | Selects the part the Effects menu changes |
| Spotlight | `O` | Dims everything outside it |
| Magnify | `G` | A round callout showing a part bigger |

**From the keyboard:**
- Choose a tool with its key, then press **Enter**: an item of the usual size appears in the middle.
- **Tab** and **Shift+Tab** select one annotation after another.
- The arrows move the selected one (Shift: 10 px); **Shift+Ctrl+arrows** resize it.
- **Delete** removes it.

## The Image and Effects menus

- **Image:** rotate (by 90° or any angle), flip, resize, change the canvas size, trim plain borders.
- **Effects**, on the whole image or the part selected with Area:
  - frames: drop shadow, torn edge, faded edges, border, rounded corners, perspective;
  - colour: brightness and contrast, grayscale, sharpen;
  - **Watermark:** text or a picture, placed in a corner, along an edge or repeated.

  The Effects window shows the result live. Stacks of effects and watermarks can be saved as presets.

## Saving and sending

| Keys | |
|---|---|
| `Ctrl+S` | Save (a capture saved before is overwritten) |
| `Ctrl+Shift+S` | Save as PNG, JPEG or BMP |
| `Ctrl+C` | Copy the image with its annotations |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |

**Send to** sends the image to any destination: printer, Word, PowerPoint, PDF, servers, uploads, other apps. **Continue** runs the rest of the after-capture workflow.

## Batch Process, Combine Images, Images to PDF

Tray › **Tools**:
- **Batch Process:** resize, apply an effects preset and a watermark, convert and rename many pictures at once.
- **Combine Images:** pictures side by side, stacked or in a grid, with spacing, a border and a background.
- **Images to PDF:** one PDF with one or several pictures per page.

Add pictures with the buttons, or drag them in from Explorer. Each tool remembers its choices.
