# CashGear Capture user guide

CashGear Capture takes screenshots, records the screen with sound, and edits both, on Windows 10 (version 2004 or later) and Windows 11. It lives in the notification area and works from hotkeys, its tray menu and a floating toolbar. It speaks English and Arabic.

**Accessibility.** Every window works from the keyboard alone, including the toolbars (Ctrl+Alt+Shift+T) and the tray icon (Win+B). Narrator and other screen readers read every control by name, the editors' annotations and clips as items, and the level meters' levels. Windows' contrast themes are followed as soon as they are switched on. See [Keyboard shortcuts](keyboard-shortcuts.md).
