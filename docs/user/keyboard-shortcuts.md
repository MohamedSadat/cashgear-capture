# Keyboard shortcuts

Everything in CashGear Capture can be done from the keyboard. Key names are the same in Arabic (they match the keys).

## Hotkeys (anywhere in Windows)

Change them in Settings › Hotkeys. The ones with "—" have no key until you set one.

| Default | Action |
|---|---|
| `PrintScreen` | Capture a region |
| `Alt+PrintScreen` | Capture the active window |
| `Ctrl+PrintScreen` | Capture the full screen |
| `Ctrl+Shift+PrintScreen` | Scrolling capture |
| `Ctrl+Alt+PrintScreen` | Capture text (OCR) |
| `Shift+PrintScreen` | Start a recording, or stop it |
| `Ctrl+Alt+Shift+PrintScreen` | Repeat the last capture |
| `Ctrl+Shift+D` | Draw on the screen (while recording) |
| `Ctrl+Alt+Shift+T` | Use the capture or recording toolbar from the keyboard (Tab, Enter; Esc gives the focus back) |
| — | Capture a window, fixed-size, freehand, polygon or rounded region, object, open menu |
| — | Show or hide the capture toolbar; the magnifier, colour picker, ruler, crosshair |
| — | Push-to-talk (hold) |

## The tray menu

`Win+B` moves to the notification area. Arrow to the CashGear Capture icon (open **^** with Enter if it is hidden), then `Enter`, `Space` or `Shift+F10` opens the menu. In the menu: arrows, the underlined letters, `Enter`, `Esc`.

## Selecting an area (region, window, recording)

| Keys | |
|---|---|
| `Enter` | Capture the highlighted area, window or monitor |
| `Esc` | Cancel |
| Arrows (`Ctrl`: 10 px) | Move the pointer a pixel |
| `Tab` | Next size (fixed-size region) |
| `Backspace` | Take back the last corner (polygon) |

## A countdown

`Esc` cancels the capture.

## The image editor

| Keys | |
|---|---|
| `V` `A` `L` `R` `E` `D` `H` `T` `N` `B` `X` `C` `M` `O` `G` | Select, arrow, line, rectangle, ellipse, pen, highlight, text, step number, blur, pixelate, crop, area, spotlight, magnify |
| `Enter` (with a tool) | Add an item of the usual size in the middle (with Select: edit the selected text) |
| `Tab` / `Shift+Tab` | Select the next / previous annotation (`Ctrl+Tab` leaves the picture) |
| Arrows (`Shift`: 10 px) | Move the selected annotation or the crop frame; with nothing selected, scroll |
| `Ctrl+Shift+`arrows | Resize the selected annotation by a pixel |
| `Delete` | Delete it |
| `Enter` / `Esc` (cropping) | Crop / cancel |
| `Ctrl+Z`, `Ctrl+Y` | Undo, redo |
| `Ctrl+S`, `Ctrl+Shift+S` | Save, save as |
| `Ctrl+C` | Copy the image |
| `Ctrl+0`, `Ctrl+1`, `Ctrl++`, `Ctrl+-` | Fit, 100%, zoom in, zoom out |
| `Space`+drag | Pan |

## The video editor

| Keys | |
|---|---|
| `Space` | Play / pause |
| `←` / `→` | A frame back / on |
| `Home` / `End` | To the start / end |
| `S` | Split at the playhead |
| `I` / `O` | Mark in / out |
| `Delete` / `Shift+Delete` | Delete (the range or the clip) / ripple delete |
| `Esc` | Clear the selection |
| `Tab` / `Shift+Tab` | Select the next / previous clip (`Ctrl+Tab` leaves the timeline) |
| `↑` / `↓` | Move the selected clip to the track above / below |
| `Alt+←` / `Alt+→` (`Shift`: a second) | Move the selected clip a frame |
| `Ctrl+[` / `Ctrl+]` | Trim the selected clip's start / end to the playhead |
| Arrows, in the preview (`Shift`: 10 px) | Move the selected picture, annotation or zoom (at the playhead) |
| `Ctrl+Z`, `Ctrl+Y` | Undo, redo |
| `Ctrl+S`, `Ctrl+Shift+S` | Save the project, save as |
| `Ctrl+E` | Export |
| `Ctrl++`, `Ctrl+-`, `Ctrl+0` | Zoom the timeline in, out, to fit |

## Screen tools

| Tool | Keys |
|---|---|
| Magnifier | `+` `-` zoom, arrows move a pixel (`Ctrl`: 10), `Esc` closes |
| Colour picker | Arrows move a pixel, `Enter` picks, `Esc` cancels |
| Ruler | Arrows move it (`Shift`: change its length), `Esc` closes |
| Drawing on the screen | `1`–`4` pen, highlighter, arrow, rectangle; `Ctrl+Z` undo; `Delete` or `Backspace` clear; `Esc` stop |

## Every window

`Tab` and `Shift+Tab` move between controls (the buttons at the bottom come last); `Alt` with an underlined letter opens a menu or jumps to a control that has one; `Enter` presses the default button; `Esc` closes a dialog or cancels. Narrator and other screen readers read every control's name, and Windows' contrast themes are followed as soon as they are switched on.
